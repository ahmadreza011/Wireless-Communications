# Wireless-Communications
Implementations of the computer assignments for the Wireless Communications course

## CA1

- Simulating a base-station and analyzing path-loss, shadowing effects and Power Delay Profile

- Implementing a multipath wireless channel and analyzing fading channels

- Allocating Power in wireless networks using gradient ascent algorithm

## CA2

Implementing different diversity methods (maximum ratio combining, time diversity, space diversity)

## CA3

Implementing a narrow-band channel and an OFDM system for a wide-band channel and investigating different wireless
communication concepts (waterfilling, equalizing, and clipping effect for PAPR reduction)
